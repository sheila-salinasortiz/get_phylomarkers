# 0. BEFORE GOING TO tax validate
#	0.1 Download the input sequence (see the manual of get_homologues for it) and put them in a directory (OutgroupDataset
#	0.2 Run GET_HOMOLOGUES two times
#		0.2.1 For the pangenome (-t0)
get_homologues/get_homologues.pl -d reducedDataset -m cluster -G -C 75 -E 1e-05 -t0 -P -A
#		0.2.2 For the core genoma, this results is the one for GET_PHYLOMARKERS
get_homologues/get_homologues.pl -d OutgroupDataset/ -m cluster -G -C 75 -E 1e-05 -e -P -A
#	0.3 Run GET_PHYLOMARKERS from sheila-salinasortiz GitHub repository (if not the ML matrix will not be reached)

get_phylomarkers/run_get_phylomarkers_pipeline.sh -R 1 -t PROT

#	3.1 Without genera limits

#	3.2 With genera limits

# 4. If you think there is a specie/group not correctly agrupated: 4_tSuspicious.py

#		With genera limits
